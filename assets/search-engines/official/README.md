# 検索エンジンの公式ロゴ

今のデザインの検索（ツールバーの検索ボタン・ブラウザアプリ）で使うロゴです。前のデザイン（/legacy/）は、ひとつ上のフォルダの単色版をそのまま使います。

| ファイル | 出典 |
|---|---|
| google.svg・duckduckgo.svg・brave.svg・bing.svg | SVG Logos（gilbarbara/logos、CC0）。各社の公式ロゴの色・形のまま |
| mojeek.svg | Simple Icons（出典: https://www.mojeek.com/logos）。Mojeekの公式マークは緑の単色です |

ロゴは各社の商標です。検索先を示す目的でだけ使っています。
