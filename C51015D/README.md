# C51015D

`https://superzero1288.github.io/C51015D/` で公開している、独立したサイトです。
ぜろくんでんせつ のリポジトリに置いていますが、あちらのサイトからはリンクしておらず、サイトマップにも載せていません。
デザインは、ぜろくんでんせつ のサイトの前のデザインにあった「LiquidGlass」（すりガラス）をもとにしています。

## デザインの考え方

- 背景の写真（いまは仮の写真）の上に、LiquidGlass（すりガラス）の板を浮かべます。写真は画面に固定で、スクロールしても動きません。
- ガラスの板は、プロフィール・各セクション（About・Works・note記事・Links）・フッター・スマホのタブ・記事ページの上のバーと本文です。
- 文字はすべてガラスの上に置き、写真の上に直接は置きません。写真のどこが後ろに来ても読めるよう、ガラスの濃さと文字の色を決めています（テストで実際の画面の色を測って確かめています）。
- トップページはPCだと左にプロフィールと目次（画面の上下の真ん中、中央揃え）、右に本文。スマホではプロフィールが上に来て、目次は上に浮かぶタブになります。
- 色は「文字・補助の文字・線・アクセント」と、ガラスの色。アクセント（朱色）は「今いる場所」と「操作できるもの」にだけ使います。
- 表示（自動・ライト・ダーク）はページのいちばん下で切り替えられます。「自動」はOSの設定に従います。ダークでは背景の写真を少し暗くします。
- OSの「透明度を下げる」設定のときは、ガラスを不透明にします。

## 背景の写真を変える

`assets/wallpaper.webp` を同じ名前の画像に置きかえます。別の名前にするときは、`assets/style.css` の先頭の `--wallpaper:url("wallpaper.webp");` を書きかえます。
写真によっては文字が読みにくくなることがあるので、変えたらテスト（`npm test`）で確かめてください。

今は中身が決まっていないので、テンプレート（仮の文章）になっています。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（左にプロフィールと目次、右に About・Works・note記事・Links） |
| `blog/index.html` | note記事の一覧 |
| `blog/記事ID.html` | noteから同期した記事（自動で作られます） |
| `404.html` | このサイトの中で存在しないページを開いたときの画面 |
| `config.json` | サイト名と、noteの同期の設定 |
| `assets/style.css` | 見た目（色・ガラス・背景の写真は先頭の `:root`） |
| `assets/site.js` | 表示の切り替え・スマホのタブ・今いる場所の表示 |
| `assets/theme.js` | 保存したダーク/ライトを最初に反映 |
| `assets/icon.svg` | タブのアイコン |
| `assets/wallpaper.webp` | 背景の写真（仮） |
| `assets/avatar.*` | プロフィールのアイコン（noteの同期で自動で保存されます） |
| `scripts/sync-note.mjs` | noteの記事を同期するスクリプト |

ページ同士のリンクや画像は、すべて相対パス（`./` や `../` から始まる、または何も付けない書き方）にしています。
`/` から始まる書き方にすると ぜろくんでんせつ のサイトを指してしまうので、使わないでください。
こうしておくと、あとでこのフォルダごと別のリポジトリや独自ドメインに移しても、そのまま動きます。

## 中身を書きかえる

- `index.html` を開き、各セクションの仮の文章（灰色で表示される部分、`class="muted"`）と、Works の「サンプル」の行を書きかえます。
- プロフィールのアイコンは、noteの同期がnoteのアイコンを取ってきて自動で入れます（`index.html` の `<!-- AVATAR_START -->` と `<!-- AVATAR_END -->` の間）。
- リンク（Links・Works）は、行の `<div class="row">…</div>` を `<a class="row" href="https://..." target="_blank" rel="noopener">…</a>` に変えます。最後に `<span class="row-go" aria-hidden="true">↗</span>` を足すと、外部リンクの印が付きます。

## noteの記事を同期する

1. `config.json` の `note.user` に noteのID（`https://note.com/〇〇` の 〇〇 の部分）を書きます。いまは `roritec` です。
2. GitHub の Actions にある「C51015D: note記事を同期」が、6時間ごとに記事を確認して、新しい記事をサイトに追加します（すぐ試すときは Actions から手動で実行できます）。
3. 同期のたびに、noteのアイコンも取ってきて、トップページのアイコンにします（noteでアイコンを変えると、次の同期でこちらも変わります）。

- トップページには新しい順に `note.homeCount` 件（はじめは3件）、記事一覧には全件が並びます。
- `note.user` が空のあいだは、同期は何もしません。
- 有料記事や限定公開の部分は取得しません。
- デザインを変えたときは `node C51015D/scripts/sync-note.mjs --rebuild` で、通信せずに記事ページを作り直せます。

## 公開するとき

今は検索結果に出ない設定（`noindex`）にしています。中身ができたら、

- `index.html` と `blog/index.html` の `<meta name="robots" content="noindex">` の行を消す
- `config.json` の `noindex` を `false` にする（同期で作る記事ページに反映されます）

## 注意

- ぜろくんでんせつ のサイトと同じドメインなので、ブラウザの保存データ（localStorage）は、お互いのページから読み書きできる状態です。このサイトの保存データの名前は `c51015d:` で始めて、混ざらないようにしています。
- `/C51015D/` の中で存在しないページを開くと、サイト全体の404ページ（ルートの `404.html`）が、このサイトの `404.html` へ移動させます。
