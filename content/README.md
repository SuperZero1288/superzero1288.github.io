# サイトに表示する文章

ここにあるテキストファイルを書きかえると、サイトの表示が変わります。HTMLを触る必要はありません。
保存して `main` に入れると、GitHub Pagesに反映されます（ブラウザに古い内容が残っているときは再読み込みしてください）。

| ファイル | 表示する場所 | 書き方 |
|---|---|---|
| `hero-messages.txt` | トップページの名前の下と、いちばん下のフッター | 1行に1つ。ページを読み込むたびにランダムで1つ選ばれます（前回と同じものは続けて出ません） |
| `profile-pc.txt` | 「詳しいプロフィール」のPC環境 | 1行に1つ、`見出し: 内容` の形（例: `CPU: AMD Ryzen 7 3700X`）。書いた順に並びます |
| `profile-phones.txt` | 「詳しいプロフィール」のスマホ布陣 | `profile-pc.txt` と同じ |

- 空の行は無視されます。
- 見出しと内容は、最初の `:`（半角）か `：`（全角）で区切ります。
- 文字コードはUTF-8のまま保存してください。
